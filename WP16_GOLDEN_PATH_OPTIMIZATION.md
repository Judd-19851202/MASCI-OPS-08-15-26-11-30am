# WP16 Golden Path Optimization

## Objective
The Golden Path is the shortest trustworthy path through the platform’s most common work. WP-16 requires every shared experience decision to improve the Golden Path before edge-case complexity is added.

## Golden Path principles
- Prefer selection over typing.
- Prefer defaults over setup.
- Prefer visible next steps over hidden affordances.
- Prefer one-screen completion over multi-step drift.
- Prefer honest empty states over dead ends.

## Platform-wide optimization rules
- Reduce click count before adding features.
- Reduce vertical travel before adding density.
- Eliminate duplicate data entry before adding automation.
- Keep helper text close to the decision point.
- Keep recovery actions near the error state.

## Workflow readiness gate
No workflow is considered optimized until:
- navigation path is canonical
- shell is modernized
- copy is operator-safe
- mobile ergonomics are acceptable
- exit path is obvious
- evidence and trust messaging remain intact
