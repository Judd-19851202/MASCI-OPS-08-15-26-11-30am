## Governing principle

A defect or capability is **not** fixed because a screen changed, an endpoint returned `200`, a test passed, a screenshot looked correct, the original symptom disappeared, an agent reported PASS, or a release gate stayed green.

A defect or capability is fixed only when:

1. the root cause and applicable failure class are eliminated end-to-end;
2. all legitimate upstream and downstream relationships work;
3. all appropriate engines and consumers receive correct governed truth;
4. the complete human workflow works;
5. permanent regression protection prevents recurrence.

## Core constitutional rules now in force

1. **Root cause before repair** — trace symptom → root cause → shared/systemic cause → affected authority/data → surfaces → workflows → consumers → repair.
2. **Failure-class elimination** — ask where else the same class of failure can exist and inspect the full applicable denominator.
3. **One canonical authority** — every material business fact must follow `Source → Canonical Authority → Governed Evidence/Trust → Derivation/Engine → Authorized Consumers`.
4. **Complete platform integration** — prove legitimate producer → authority → trust → engine → API → workflow → portal → KPI/dashboard → notification/task → PDF/export → history → downstream consumer chains.
5. **End-to-end workflow completion** — every legitimate workflow stage must function where applicable.
6. **Human operability is a release requirement** — technical correctness without understandable human workflow is not completion.
7. **Truthful state is permanent** — `LOADING ≠ ZERO`, `UNKNOWN ≠ ZERO`, `UNAVAILABLE ≠ ZERO`, `NO ACCESS ≠ ZERO`, `STALE ≠ CURRENT`, `INSUFFICIENT EVIDENCE ≠ GREEN`.
8. **Deterministic propagation / invalidation** — downstream truth must update or explicitly become stale.
9. **Canonical identity** — deterministic linkage only; ambiguity remains unresolved/reviewed, never fabricated.
10. **Trust Spine / governance truthfulness** — no green through suppressed failures, relaxed thresholds, hidden stale evidence, fabricated evidence, or contamination.
11. **Cross-surface parity** — same semantics must reconcile across legitimate consumers; differences must be obvious.
12. **Outputs are first-class consumers** — PDF, email, notification, print, CSV/export, history, and audit outputs must reconcile with UI truth.
13. **Authorization / scope end to end** — UI, API, direct URL/object access, project scope, object-level privacy, and role lifecycle must all be proven.
14. **Shared behavior requires shared ownership** — shared failures require shared primitives/authorities, not page-local patching.
15. **Every material defect leaves a tripwire** — durable regression protection is required whenever technically feasible.
16. **Runtime reality required** — browser/runtime proof plus source/API/role evidence outranks paper certification.
17. **Original owner-observed defect must be revisited** — allowed final dispositions are only `CLOSED — DIRECT RUNTIME CERTIFIED` or `NOT APPLICABLE — FACTUALLY PROVEN`.
18. **Blast-radius regression** — regression scope must match shared repair scope.
19. **No backlog escape** — in-scope defects cannot be moved to future/polish merely to obtain closure.
20. **Certified behavior contract freeze** — once fully certified, behavior becomes an inherited contract until explicitly amended.
21. **Permanent Fix Closure Register required** — every material finding must be tracked through root cause, repair, proof, regression, blast radius, and frozen contract.
22. **Definition of CLOSED** — all applicable proof dimensions must exist; missing applicable evidence means **NOT CLOSED**.
23. **Definition of DONE** — every in-scope defect/capability closed under this doctrine; only then may a package be called `GO — READY TO SAVE & DEPLOY`.

## Permanent rule

**Fix it once. Fix the root. Fix the failure class. Fix every legitimate connection. Prove the truth. Prove the complete human workflow. Protect the fix from regression. Freeze the certified contract. Then — and only then — call it closed.**
