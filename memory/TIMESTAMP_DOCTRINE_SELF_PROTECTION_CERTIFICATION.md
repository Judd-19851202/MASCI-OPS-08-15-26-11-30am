## How it enforces itself (operator narrative)

1. A developer accidentally writes `(x || "").slice(0, 16).replace("T", " ")`
   in a new operator-facing surface.
2. They run `bash scripts/pre_deploy_check.sh` before the Save + Deploy.
3. `stage_timestamp_doctrine` runs the probe.
4. The probe detects the new line (not in the baseline · severity high).
5. The gate fails with the exact file, line, pattern, and fix hint.
6. The developer either:
   - Fixes the code (uses `formatLocalDateTime` from `dateUtils.js`), or
   - Adds the line to the baseline via `--bless` (only if it's a
     reviewed legacy admin/audit surface).
7. The gate now passes and the build can proceed.

The platform's timestamp doctrine has become **self-enforcing**.
