**Owner:** MASCI Operations (Jay)

## 0 · How to use this brief

1. Editor pulls all platform clips from the **Promo Asset Library** at `/admin/promo-assets`.
2. Editor pulls field footage from MASCI's Google Photos / drone library / shop archives.
3. Editor follows the **shot list** in §4 to build the 60–75 sec cut.
4. Editor delivers 5 exports per §10 back into the library (visibility = `public` for the public ones).
5. MASCI sets the three env vars in §11 → homepage hero loop goes live.

### Capture style requirements (enforced)
- **🎬 Append `?capture=1` to every URL before recording.** This activates capture-mode and hides every operational banner: Memorial Day banner, holiday/advisory/safety-alert banners, "Backend reconnecting…" status banners, admin-only persistence health alerts. Stays on for the duration of the tab.
- Clean cursor movement — no jitter, no overshoot
- Short pauses on important moments (Refs, banners, status flips)
- NO loading spinners on camera (pre-warm the page before the take)
- NO browser chrome (use fullscreen or window-only recording)
- NO embarrassing test data (`asdf`, `test123`, dev emails)
- NO raw FastAPI errors (iter346 should have eliminated these — verify before take)
- NO active operational banners across platform clips — capture-mode handles this automatically
- NO empty states unless intentional
- Production-safe data only

#### Toggle reference (capture-mode)
| URL appended | Effect |
|---|---|
| `?capture=1` | Hides ALL operational banners for the tab session |
| `?capture=0` | Returns to normal (banners visible) |
| _(no param)_ | Normal operator view (default) |

When capture-mode is on, the data still polls in the background — toggling off restores live banners instantly. Zero footprint when off.

## 9 · Transitions / editing

- Hard cuts ON BEAT — every transition rides the music's percussive elements.
- Speed-ramps allowed twice MAX. Don't get cute.
- Whip-pans only between Act 1 ↔ Act 2 (problem reveal).
- Match-cuts encouraged: hand-on-tablet → cursor-on-screen.
- Subtle motion-graphics overlays on platform clips (UI HUD ticks, status pings) — keep them dark / muted / one-color.
- NO PowerPoint wipes. NO spinning transitions. NO 90s software-demo cuts.
- Color: cool slate base, warm accent on equipment / golden-hour exteriors.

## 11 · Homepage embed wiring (deploy-ready)

Once the editor delivers the Hero Loop (cut #2), MASCI sets these three env vars and the `<PromoHeroLoop />` component on the homepage goes live:

```
REACT_APP_PROMO_HERO_LOOP_URL = <7-day signed R2 URL or public URL for cut #2>
REACT_APP_PROMO_FULL_VIDEO_URL = <signed/public URL for cut #1>
REACT_APP_PROMO_POSTER_URL    = <signed/public URL for a 1-frame poster image>
```

Component path: `/app/frontend/src/components/PromoHeroLoop.jsx`
- Mounted optionally on `Hub.jsx` (renders nothing until `REACT_APP_PROMO_HERO_LOOP_URL` is set)
- Hero autoplays muted with `playsInline` (iOS-safe)
- Click → modal opens with full film
- ESC / backdrop click closes
- Mobile-responsive `aspect-video` container
- Fallback to poster if video fails

Until env is wired, `<PromoHeroLoop />` returns `null` — zero footprint, zero risk.

## 12 · Asset naming conventions (enforced for the library)

```
{Workflow}_{Device}_{Aspect}_{Resolution}.mp4
{Workflow}_{Device}_{Aspect}_{Resolution}_{LanguageOpt}.mp4

Examples:
  DailyReport_Workflow_Desktop_16x9_1080p.mp4
  DailyReport_Mobile_9x16_1080p_ES.mp4
  HeroLoop_Homepage_16x9_1080p_MUTED.mp4
  Bilingual_Toggle_Desktop_16x9_1080p.mp4
```

When uploading via the Promo Asset Library admin page, fill in:
- **Name** = full descriptive title (e.g. "Daily Report Workflow · Desktop")
- **Category** = pick from the 26-option dropdown
- **Tags** = `daily-report, field, desktop, workflow` (lowercase, kebab-case, comma-separated)
- **Visibility** = `internal` (default — only admins see the signed URL) or `public` (long-TTL signed URL safe to share externally)
- **Duration / Resolution / Aspect** = optional but recommended for editor handoff
