# WP18CX Executive Language Standard

## Executive-facing requirement
Executive pages must sound like leadership operating reviews, not platform diagnostics.

## Approved executive terms
- `Executive Operations Dashboard`
- `Current portfolio view`
- `Projects needing leadership review`
- `Recovery overdue`
- `Briefing status`
- `Monday Morning Briefing`

## Disallowed executive terms on visible surfaces
- canonical shell
- backend shorthand
- technical engine names
- trust-line jargon without an operating consequence

## Certified updates in this package
- renamed executive dashboard to `Executive Operations Dashboard`
- rewrote hero copy to plain-English leadership language
- rewrote Executive Overview mission text to `shared work area` wording
