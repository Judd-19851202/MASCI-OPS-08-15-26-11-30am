## 2 · Foundation API surface

### 2.1 · `get_white_label() -> WhiteLabelConfig`
Frozen dataclass: `brand_name`, `brand_long_name`, `brand_logo_url`,
`brand_color`, `footer_tagline`, `company_legal_name`, `platform_owner`.
Reads `PDF_BRAND_*` env vars per call (no caching) so config changes
take effect on the next render without a backend restart.

### 2.2 · `build_audit_block_html(record_id, source_module, project=None, document_version=None, generated_by=None, generated_at=None) -> str`
Returns a `<div class="t1541-audit">` snippet with a mono-spaced table:
* Record ID · Source Module · Project · Document Version · Generated By · Generated On · Environment · Foundation
Page-break-avoidant. Last-page friendly. ~250 bytes of inline CSS.

### 2.3 · `build_metadata_block_html(document_type, document_id=None, project_number=None, extra=None) -> str`
Returns a `<div class="t1541-meta">` snippet — small monospace strip
with `DocType · DocID · Project# · Generated · Env`.

### 2.4 · `PDF_FOUNDATION_VERSION = "15.41.1"`
Embedded in every audit block. Bump on future foundation revisions.

### 2.5 · `_env_tag()`
Derives PREVIEW / STAGING / DEV / PRODUCTION / UNKNOWN from `DB_NAME`.
