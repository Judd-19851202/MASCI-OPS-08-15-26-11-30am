⚠️ **Before rotating prod `MFA_ENCRYPTION_KEY`:** check whether ANY prod user has MFA actually enrolled with a TOTP secret. If yes, those users will lose their TOTP and need to re-enroll. Query (operator-runnable from prod pod or via shared cluster cred from preview pod):

```python
import asyncio, os
from motor.motor_asyncio import AsyncIOMotorClient
mc = AsyncIOMotorClient(os.environ["MONGO_URL"])
db = mc["masci_safety"]
n = await db.user_directory.count_documents({"mfa.enrolled": True})
print(f"prod users with MFA enrolled: {n}")
```

If `n > 0`, plan a coordinated re-enrollment window before rotating `MFA_ENCRYPTION_KEY`. The other two secrets (`JWT_SECRET`, `ADMIN_HMAC_SECRET`) can be rotated immediately.
