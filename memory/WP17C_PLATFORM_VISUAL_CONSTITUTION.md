# WP17C Platform Visual Constitution

This constitution governs every MASCI OPS portal, route, form, dashboard, and workflow.

## Articles
1. One platform shell family only: `PortalShell`, `PortalLoginShell`, `FormShell`.
2. One MASCI logo standard only via `MasciLogo`.
3. One semantic token system only via `wp17.css` and approved extensions.
4. Portal identity may not replace platform identity.
5. Route-local wrappers are prohibited when a canonical shell exists.
6. Route-local hard-coded visual values require a documented exception.
7. A shared component import does not equal certification; rendered output rules.
8. Responsive certification is mandatory at 390, 768, 1024, and 1440 widths.
9. Visual drift must be logged, not hidden.
10. Legacy components must be removed after successful migration.
