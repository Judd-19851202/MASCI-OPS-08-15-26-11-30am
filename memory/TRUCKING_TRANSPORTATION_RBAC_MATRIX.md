# Trucking / Transportation RBAC Matrix

Per-surface role/permission requirements. Generated by Track 17.00.

Roles considered:
- **Admin** (super-admin · `require_admin_dep`)
- **Dispatch** (dispatch portal user · `require_dispatch_or_admin`)
- **PM** (PM portal · `X-PM-Token`)
- **HR** (HR portal · `X-HR-Token`)
- **Safety** (Safety portal · `X-Safety-Token`)
- **Field Leadership** (FL portal · `X-FL-Token`)
- **Shop** (Shop portal · `X-Shop-Token`)
- **External carrier** (signed token via `/transport-invite/:token`)
- **Driver** (driver session token via magic link)
- **Anonymous** (no auth · public endpoints only)

## Read-only consumer pattern (cross-portal)

Established by Track 16.11A and Track 16.16:

* **Single endpoint** wraps multiple existing builders.
* **Gated by `make_require_any_portal_token`** — accepts admin /
  pm / dispatch / hr / safety / fl / shop tokens.
* **No writes** — pure composer.
* **No new scoring** — only reuses existing engines.

Future Operations-side widgets should follow this contract.
