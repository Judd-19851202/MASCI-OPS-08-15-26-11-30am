## 4. Why this is structurally impossible to violate

The IAM substrate (`userBadges.js`, `IamBadges.jsx`, `IamStandardCells.jsx`)
contains **only pure reducers and pure React components**. Reducers read the
user object passed by the parent panel and return a string/state-enum. The
React components render JSX. There is no `fetch`, no `axios`, no global state
mutation. The substrate cannot — by static analysis — invoke a backend write.

The 8 panel patches consist of `import` statements and a `<IamStandardCells/>`
JSX insert. Neither introduces a side-effect path.
