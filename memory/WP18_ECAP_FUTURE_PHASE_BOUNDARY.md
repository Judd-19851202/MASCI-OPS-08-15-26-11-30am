# WP18 ECAP Future Phase Boundary

Date: 2026-08-03

## Final boundary decision

**Decision label:** `APPROVED_CONSTITUTIONAL_DECISION`  
**Proof label:** `DOCUMENTED_ONLY`

WP-18C is intentionally bounded.

## Explicitly in WP-18C

- hierarchy propagation
- authority/source-of-truth enforcement
- Budget Hierarchy
- cost-code / estimate mapping
- schedule/actuals governance
- production / quantity model
- forecasting / commitments
- Earned Value
- executive reporting hierarchy
- migration / backfill / certification

## Explicitly outside WP-18C

- broad portal redesign
- authentication replacement
- backup/recovery redesign
- accounting general ledger replacement
- speculative new AI authority surfaces
- speculative new enterprise hierarchy levels not accepted in ECAP

## Future-phase law

Any work outside the WP-18C boundary requires a later separately evidenced authorization.
