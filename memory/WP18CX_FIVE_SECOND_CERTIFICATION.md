# WP18CX Five Second Certification

## Standard
An operator should understand location, scope, health, and next action within five seconds.

## Runtime-certified passes
| Surface | Five-second result | Evidence |
|---|---|---|
| PM Project Controls | Pass | title + summary cards + action sections are immediate |
| PM Project Budget | Pass | title + summary cards + review sections are immediate |
| PM Project Schedule | Pass | title + summary cards + review/planning labels are immediate |
| PM Project Performance | Pass | current view + review/recommendation labels are immediate |
| Admin governance pages | Pass | review-oriented page titles and counts are immediate |
| Executive dashboard | Pass | current portfolio view + risk/briefing wording is immediate |

## Remaining caveat
Five-second certification is not yet fully recorded for Safety / HR / Dispatch / Shop / Equipment / Survey dedicated runtime surfaces.
