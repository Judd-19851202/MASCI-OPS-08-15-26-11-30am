## During WP-18C

**Decision label:** `APPROVED_CONSTITUTIONAL_DECISION`  
**Proof label:** `DOCUMENTED_ONLY`

WP-18C must:

- execute only the defined sub-packages
- preserve protected systems by default
- use additive migration and backward compatibility
- stop on any ECAP stop condition
- inherit the WP-17 Product Constitution, the WP-18 ECAP, the WP-18 Operational Intelligence Constitution, and the WP-18 Operational Decision Engine Constitution
- reduce duplicate entry and operator workload where the package legitimately touches workflows
- increase operational intelligence and downstream value instead of only collecting more data
- follow the governed decision pipeline from capture through learning/improvement where the package legitimately touches that flow
- close each package only with the evidence defined in the acceptance matrix

## Explicit WP-18C exclusions

**Decision label:** `APPROVED_CONSTITUTIONAL_DECISION`  
**Proof label:** `DOCUMENTED_ONLY`

Excluded from WP-18C unless separately authorized:

- replacing protected portal or domain architecture without an approved reopening trigger
- changing authentication architecture without evidence of critical defect
- replacing validated PDF/email/report infrastructure
- converting ForgedOps into the accounting general ledger
- introducing hidden net-new major subsystems beyond Budget Hierarchy and Earned Value

## Implementation authority law

**Decision label:** `APPROVED_CONSTITUTIONAL_DECISION`  
**Proof label:** `DOCUMENTED_ONLY`

Routine implementation choices that conform to ECAP do **not** require repeated executive review.

Every future package must open with language equivalent to:

> This work package inherits the WP-17 Product Constitution, the WP-18 Executive Constitutional Architecture Package (ECAP), the WP-18 Operational Intelligence Constitution, and the WP-18 Operational Decision Engine Constitution. Compliance is mandatory.

Implementation must stop only when it encounters:

- contradiction with ECAP
- protected-subsystem rebuild proposal
- ambiguous source-of-truth ownership
- unreconcilable financial truth
- destructive migration risk
- unauthorized permission change
- unavailable required external dependency
- scope expansion beyond the authorized sub-package

## Final contract result

WP-18C is contractually authorized to begin **only** under the ECAP sequencing, scope, and evidence rules.

Every later package after WP-18 inherits the same constitutional stack unless a later executive amendment explicitly supersedes it.
