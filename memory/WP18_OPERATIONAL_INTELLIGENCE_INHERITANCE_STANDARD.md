# WP-18 Operational Intelligence Inheritance Standard

Date: 2026-08-04

## Constitutional status

**Decision label:** `APPROVED_CONSTITUTIONAL_DECISION`  
**Proof label:** `EXECUTIVE_DIRECTIVE`

## Mandatory opening language for all future work packages

Every future implementation package should begin with language equivalent to:

> **This work package inherits the WP-17 Product Constitution, the WP-18 Executive Constitutional Architecture Package (ECAP), and the WP-18 Operational Intelligence Constitution. Compliance is mandatory.**

## Scope of automatic inheritance

This inheritance applies automatically to:

- every remaining WP-18 package
- WP-19
- WP-20
- every later package unless a future executive constitutional amendment explicitly supersedes these foundations

## Minimum package-level compliance statement

Every future package must explicitly state:

1. how it reduces operator work
2. how it reuses captured facts downstream
3. how it increases operational intelligence
4. how it increases executive visibility
5. which authoritative truth owners it consumes without duplicating
6. how AI remains advisory only
7. what downstream value proves package completeness

## GO gate rule

No future implementation, audit, redesign, enhancement, or certification may receive **GO** unless it passes constitutional self-evaluation against:

- the WP-17 Product Constitution
- the WP-18 ECAP
- the WP-18 Operational Intelligence Constitution

## Backward-compatibility rule

Previously completed packages are not reopened or redesigned merely because this standard is now explicit.

They are to be:

- preserved
- declared inheritors of the new constitutional layer
- checked for genuine constitutional gaps
- enhanced only where later packages legitimately need that work
