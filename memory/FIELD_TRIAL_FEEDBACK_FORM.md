## RULES FOR THE OBSERVER

* **Capture verbatim quotes**. Use quotation marks. Use the foreman's exact words.
* **Do NOT summarize away complaints.** If the foreman says "this thing is stupid", write down "this thing is stupid", not "form was not intuitive."
* **Do NOT defend the platform.** Listen. Capture. Move on.
* **Do NOT prompt with the answer.** Open questions only.
* **Include profanity if used** (we want signal, not polite cooperation).
