# WP18CX Construction Terminology Standard

## Rule
Construction work terms outrank software architecture terms on every operator-facing surface.

## Approved examples
- `Project Performance`
- `Items needing review`
- `Work Blocks`
- `Project Schedule`
- `Project Budget`
- `Update existing records`
- `Recommended actions`

## Prohibited examples on operator surfaces
- `governed`
- `authority` when simpler job-language exists
- `backfill`
- `orphan`
- `canonical shell`
- `runtime testing`

## Surface-level application completed in WP18CX
- sidebars
- PM headers
- admin governance headers
- review queue labels
- recommendation controls
- executive mission wording

## Inheritance rule
Future work packages may not introduce a second label for any already-certified operational concept.
