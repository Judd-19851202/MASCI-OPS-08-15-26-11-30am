# WP18CX Executive Operator Experience Regression Checklist

Use this checklist before any future package requests executive review.

## Constitutional inheritance checks
- [ ] WP-17 Constitution preserved
- [ ] ECAP preserved
- [ ] Operational Intelligence Constitution preserved
- [ ] Operational Decision Engine Constitution preserved
- [ ] WP18CX language dictionary referenced before any operator-facing wording changes
- [ ] No C1–C6 authority, trust line, or architectural replacement introduced

## Construction language checks
- [ ] No visible operator-facing use of: domain, entity, artifact, consumer, provider, snapshot, canonical, lineage, runtime, pipeline, engine, service, schema, API, contract (unless legal)
- [ ] Navigation uses construction workflow labels
- [ ] Page titles use operator-safe job language
- [ ] Empty states use construction-first language
- [ ] Buttons and alerts avoid software-developer jargon

## Decision-first checks
- [ ] Every major page answers: what is happening?
- [ ] Every major page answers: why is it happening?
- [ ] Every major page answers: is it important?
- [ ] Every major page answers: what should I do?
- [ ] Every major page answers: who owns it?
- [ ] Every major page answers: when must it be resolved?
- [ ] Every recommendation shows evidence and confidence

## Five-second / superintendent / executive checks
- [ ] Five-second test passed on desktop
- [ ] Five-second test passed on mobile
- [ ] Superintendent could understand headings, cards, warnings, and actions without translation
- [ ] Executive screens immediately show health, risks, opportunities, and next actions

## Coaching and explainability checks
- [ ] Recommendations explain why
- [ ] Recommendations explain evidence
- [ ] Recommendations explain assumptions or watchouts
- [ ] Recommendations explain consequence of inaction
- [ ] KPI labels explain themselves without architecture jargon

## Duplicate-entry checks
- [ ] No new duplicate operator input introduced
- [ ] Existing truth can be reused before asking the operator again
- [ ] Work Block centrality preserved where applicable

## Role authenticity checks
- [ ] President / COO / VP Operations surfaces verified
- [ ] Area Manager / Project Executive / PM surfaces verified
- [ ] Superintendent / Foreman / Field Leadership surfaces verified
- [ ] Dispatch surfaces verified
- [ ] Shop / Equipment surfaces verified
- [ ] Safety surfaces verified
- [ ] HR / Payroll surfaces verified
- [ ] Survey surfaces verified

## Channel checks
- [ ] Web runtime verified
- [ ] Mobile runtime verified
- [ ] PDF output wording verified
- [ ] Export wording verified
- [ ] Email wording verified
- [ ] Notification wording verified
- [ ] AI-generated wording verified
- [ ] Accessibility spot-check completed

## QA evidence checks
- [ ] Screenshot evidence captured
- [ ] Targeted lint passed on touched files
- [ ] Testing report stored in `/app/test_reports/`
- [ ] Any QA findings fixed before executive review

## Final gate
- [ ] Platform feels like it was designed by elite heavy-civil operators rather than software developers
- [ ] No constitutional conflicts remain
- [ ] GO / NO-GO recommendation updated from runtime evidence only
