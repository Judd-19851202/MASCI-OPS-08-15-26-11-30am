## §2 · Core ownership rules (forward-binding · effective immediately)

| # | Rule | Forward-binding consequence |
|---|---|---|
| O-1 | **Ownership is inferred** — derived from S1 Creator · S2 Project · S3 State-gate · S4 Manager ladder | Any future proposal that requires manual ownership entry is presumed unconstitutional |
| O-2 | **Ownership is never manually assigned** | No "Assignee" dropdown · no "Assign To" UI · no "Pick Owner" affordance · ever |
| O-3 | **Ownership transfers through state transitions** | Reassignment is a side-effect of state change · never a standalone action |
| O-4 | **Ownership escalates automatically** up the `manager_employee_id` ladder at SLA breach | No user-initiated "Escalate" button · no "Snooze escalation" affordance |
| O-5 | **Operational records ARE the work** | No parallel task object · no ticket queue · no Jira/Monday board UI · no second representation of work besides the operational record itself |
| O-6 | **No task-management paradigm** | Task-management software patterns (assignee fields · accept/reject · status colors as ownership signals · Kanban columns) are forbidden |
| O-7 | **No acceptance workflow** | "Accept Task" / "Decline Task" affordances forbidden |
| O-8 | **No acknowledgement workflow** | Amendment 001 textbook · every ack proposal must pass the Constitutional Test |
| O-9 | **No ticket-board workflow** | Records are surfaced in Action Consoles (one-tap action affordances per row) · never as static columns or boards |

## §4 · Mandatory pre-build gate (new)

Every future build authorization for any workflow, surface, integration, or schema change must pass an **Ownership Doctrine Test**:

| Test question | If FAIL → |
|---|---|
| Is ownership inferred (S1–S4) at every state? | Re-scope until inference is deterministic OR cite Tier 5 dead-letter fallback explicitly |
| Are all transfers driven by state transitions (no standalone reassign UI)? | Remove reassign UI · model the transition |
| Are all closures driven by Tier 1 work-performed evidence? | Replace ack-click with evidence capture per Amendment 001 |
| Are all escalations automatic up the manager ladder? | Remove user-initiated escalation UI · model the SLA |
| Does the operational record carry the work (no parallel task object)? | Eliminate the parallel object · use the record itself |
| Does every executive view honor the Action Console contract? | Replace read-only with one-tap action affordances |

This test sits alongside the Constitutional Test (Amendment 001) as the second mandatory pre-build gate.
