# OSHA 29 CFR 1926 Subpart P — Requirements Matrix

**Purpose:** Authoritative list of OSHA Excavation Standard requirements MASCI must support or teach. Source-of-truth for Phase 9C-A compliance assessment. **No platform claims here** — just the regulation.

---

## §1926.650 · Scope, Application, and Definitions

| ID | Requirement |
|---|---|
| R-650.1 | "Excavation" = any man-made cut, cavity, trench, or depression in an earth surface, formed by earth removal. |
| R-650.2 | "Trench" = narrow excavation deeper than wide, ≤ 15 ft wide at the bottom. |
| R-650.3 | "Competent person" = capable of identifying existing and predictable hazards and authorized to take prompt corrective measures. |
| R-650.4 | "Protective system" = sloping/benching/shoring/shielding to protect from cave-in. |
| R-650.5 | "Tabulated data" = manufacturer/registered PE-stamped tables for protective systems. |

## §1926.651 · Specific Excavation Requirements

| ID | Requirement |
|---|---|
| R-651.1  | Underground installations must be located prior to opening excavation (§651(b)). |
| R-651.2  | Underground installations protected, supported, or removed while excavation open. |
| R-651.3  | **Access & egress** — stairway/ladder/ramp required when trench depth ≥ 4 ft, with ≤ 25 ft lateral travel to one. (§651(c)(2)) |
| R-651.4  | Ladder must extend ≥ 3 ft above the landing surface. |
| R-651.5  | Structural ramps used by personnel must be designed by a competent person. |
| R-651.6  | Exposure to vehicular traffic — high-visibility warning vests required. (§651(d)) |
| R-651.7  | Protection from falling loads — no one under suspended loads or buckets. (§651(e)) |
| R-651.8  | Warning system for mobile equipment near edge — barricades, hand/mechanical signals, or stop logs. (§651(f)) |
| R-651.9  | **Hazardous atmospheres** — tested before entry when > 4 ft deep + reasonable possibility (§651(g)). Oxygen 19.5–23.5 %. LEL < 20 %. CO ≤ 35 ppm. H₂S ≤ 10 ppm. |
| R-651.10 | Emergency rescue equipment when hazardous atmospheres exist or could exist (harness, lifelines, basket). |
| R-651.11 | **Water accumulation** — employees not allowed in trenches with accumulated water unless special precautions; water removal monitored by competent person. (§651(h)) |
| R-651.12 | Diversion ditches / dikes required if surface water may enter. |
| R-651.13 | **Stability of adjacent structures** — support systems / shoring / underpinning when excavation may affect stability. (§651(i)) |
| R-651.14 | Sidewalks, pavements, appurtenant structures not undermined unless supported. |
| R-651.15 | **Loose rock or soil** — scaling, protective barricades, or other equivalent protection. (§651(j)(1)) |
| R-651.16 | **Spoil pile / material setback** ≥ 2 ft from trench edge. (§651(j)(2)) |
| R-651.17 | **Inspections** — daily and as conditions change, by competent person, before each shift, and after rain/other hazard-increasing events. (§651(k)) |
| R-651.18 | Where evidence of cave-in possibility, employees removed until precautions complete. |
| R-651.19 | Walkways across excavations ≥ 6 ft deep — guardrails on each side. (§651(l)) |

## §1926.652 · Requirements for Protective Systems

| ID | Requirement |
|---|---|
| R-652.1  | **Protective system required at depths ≥ 5 ft** unless excavation made entirely in **stable rock**. (§652(a)(1)) |
| R-652.2  | < 5 ft only if competent person finds no indication of cave-in potential. |
| R-652.3  | Protective system selected per Appendix A (soil class) and Appendix B/C/D/E/F (system design). |
| R-652.4  | **Soil classification** by competent person using at least one visual AND at least one manual test per Appendix A. Reclassified after rain or other state change. |
| R-652.5  | **Sloping & Benching** — Type A max 53° (¾:1) / Type B max 45° (1:1) / Type C max 34° (1½:1). Benches only Type A & B. |
| R-652.6  | **Shoring / shielding** must conform to manufacturer's tabulated data OR be approved by an RPE. (§652(c)) |
| R-652.7  | **Trench shield extension** — top of shield must extend ≥ 18 in above lowest point of vertical wall it protects (or equivalent measures). |
| R-652.8  | Shields used only for depth ≤ depth rated by manufacturer / PE. |
| R-652.9  | No employees in shield during installation, removal, or vertical movement. |
| R-652.10 | **Tabulated data on site** for any manufactured equipment used as protective system, in writing. (§652(g)) |
| R-652.11 | Materials and equipment used for protective systems shall be free from damage or defects. (§652(d)) |
| R-652.12 | Damaged materials repaired only by registered PE OR removed from service. |

## Industry / Best-Practice Anchors (Road Plates)

Road plates fall outside the explicit text of Subpart P but are governed by the same hazard analysis discipline plus DOT/utility-construction norms:

| ID | Requirement |
|---|---|
| RP-1 | Capacity rating must be known and ≥ anticipated load. |
| RP-2 | Anti-skid surface (paint, weld bead, or proprietary coating). |
| RP-3 | Proper bearing — minimum 12 in overlap onto undisturbed pavement each side (most utility specs). |
| RP-4 | Pinning / anchoring required for plates over open trenches in traffic. |
| RP-5 | Cold-mix asphalt taper around perimeter to reduce vehicle impact. |
| RP-6 | High-visibility paint, reflective markings, "BUMP / STEEL PLATE AHEAD" signage. |
| RP-7 | Plate inspection on daily inspection cycle (consistent with §651(k) competent-person cadence). |
