# WP18CX Navigation and Workflow Standard

## Purpose
Define the permanent operator-facing navigation standard inherited by C7+.

## Certified labels
- PM: `Project Controls`, `Project Budget`, `Project Schedule`, `Project Performance`
- Admin: `Project Controls Standards`, `Project Budget Review`, `Project Schedule Review`, `Operations Dashboard Review`
- Executive: `Executive Operations Dashboard`

## Workflow rule
Navigation labels must match operator intent, not internal architecture.

## Certified workflow sequence
1. Set up job controls
2. Review budget structure
3. Review schedule and lookahead
4. Review field progress updates
5. Review project performance and next actions

## Five-second expectations
Within five seconds an operator must know:
- where they are
- what scope they are looking at
- whether action is required
- what the next click should be

## Smallest Safe Repair actions completed
- Removed `Authority` from PM primary navigation labels
- Replaced `Operational Intelligence` in PM navigation with `Project Performance`
- Replaced admin governance route labels with construction-first review labels

## Remaining hold points
- Runtime certification is still needed for all future mobile nav variants and channel-specific shells outside the audited PM/Admin/Executive web routes.
