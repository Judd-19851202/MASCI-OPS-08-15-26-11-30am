## 3 · Footer consistency

| Engine | Bottom-left | Bottom-right | Page numbering |
|---|---|---|---|
| WeasyPrint | `@page @bottom-left { content: "<tagline>" }` | `@page @bottom-right { content: "Page X of Y" }` | CSS-driven · always available |
| ReportLab | `draw_universal_footer(canvas, doc)` callback OR existing legacy callback | `PageNumCanvas._draw_page_of_total` (optional opt-in) | Available via `canvasmaker=PageNumCanvas`; legacy generators keep their existing footers |

Foundation footers are available for both engines but are NOT
mandatory on the legacy ReportLab generators — they continue to use
their existing footer logic (no regression).

## 4 · Brand bar consistency

| Engine | Helper |
|---|---|
| WeasyPrint | `pdf_branding.brand_header(title, kicker)` |
| ReportLab | `pdf_branding_rl.build_brand_header_flowable(title, kicker)` |

Both emit identical content: brand mark in `wl.brand_color`, optional
kicker in mono-spaced 7.5pt, optional title in 14-18pt serif. Existing
generators that already have their own headers continue using them;
new generators (or those that opt-in) use the foundation helper.
