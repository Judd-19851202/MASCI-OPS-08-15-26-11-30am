# WP18 ECAP AI and Automation Authority Constitution

Date: 2026-08-03

## Final AI authority rule

**Decision label:** `APPROVED_CONSTITUTIONAL_DECISION`  
**Proof label:** `SOURCE_VERIFIED` + `DOCUMENTED_ONLY`

AI may assist authority.  
AI may not silently become authority.

This is the standing WP-18 expression of the constitutional rule: **AI advises — humans govern**.

It is governed jointly by the WP-18 ECAP and the **WP-18 Operational Intelligence Constitution**.

## Allowed AI actions

| Action | Allowed? | Conditions |
|---|---|---|
| summarize | yes | must cite source context where possible |
| classify | yes | must preserve confidence and allow human override |
| recommend | yes | must identify rationale and limitations |
| draft | yes | draft only; human approval required |
| detect / flag | yes | alerts must be auditable and non-silent |
| prioritize | yes | only as assistive triage |
| reconcile suggestion | yes | human must approve corrections |
| coach | yes | bounded assistance only |
| forecast suggestion | yes | must never replace certified financial or schedule authority |

## Forbidden AI actions

| Action | Rule |
|---|---|
| approve financial changes | forbidden |
| alter budgets | forbidden |
| change schedules without governed review | forbidden |
| discipline employees | forbidden |
| approve terminations | forbidden |
| modify safety records without human authority | forbidden |
| certify QA/QC | forbidden |
| change payroll truth | forbidden |
| change permissions | forbidden |
| close incidents autonomously | forbidden |
| fabricate records or conceal uncertainty | forbidden |

## Required AI output metadata

Every AI output must expose:

- source evidence or source boundary
- confidence
- limitations
- required human decision authority
- auditability

AI outputs that improve understanding but do not strengthen evidence, trust, or decision quality are constitutionally insufficient.

## Final constitutional result

AI authority is fully decided for WP-18C and does not block authorization.
