# WP18 ECAP Report / PDF / Email Impact

Date: 2026-08-03

## Final decision

**Decision label:** `APPROVED_CONSTITUTIONAL_DECISION`  
**Proof label:** `DOCUMENTED_ONLY`

The current report / PDF / email framework is preserved and governed.

## WP-18C output additions

New governed outputs may include:

- budget summary reports
- forecast variance reports
- EV exception reports
- executive portfolio financial rollups
- project-controls weekly review packets

## Output rules

1. No duplicate report generator may be introduced where the existing framework can serve.
2. Every visible number in a report/PDF/email must trace to the same KPI dictionary or truth owner as the in-app view.
3. English/Spanish parity applies where the output is operator-facing.
4. Delivery is output-only; report generation does not own business truth.

## Final result

Report/PDF/email impact is fully decided and does not block WP-18C.
