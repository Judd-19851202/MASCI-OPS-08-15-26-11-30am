# WP-17B Icon Audit

## Scope
Icons were verified primarily through sidebar/domain maps, portal hubs, and Transportation child navigation because these are the highest-value operator scan surfaces.

## Findings
1. Lucide-based iconography is broadly consistent and technically reusable.
2. Admin and Transportation sometimes reuse the same icon for materially different concepts.
3. Shop, Dispatch, and Safety are strongest where one accent meaning is preserved for one operational risk family.
4. Cross-portal role objects (People, Drivers, Employees, Workers, Access) still need canonical icon ownership.

## Canonical rule for WP-17C
- One icon meaning per major object family
- One severity color system per portal
- No decorative icon swapping to imply a taxonomy change

## Disposition
- Existing icon system: `KEEP`
- Object/icon mapping inconsistencies: `STANDARDIZE`
